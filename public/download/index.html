Flagcast Manager

Set up and run your tournament from one app: teams, scores, sponsors, the screens around the clubhouse and your staff on the course.

Download Windows

Mac (Apple silicon and Intel) · Windows 10 and 11

The first public download is almost ready. Ask us at hello@flagcast.app and we'll send it to you.

Install in a minute

Mac

  1. Open the file you downloaded.
  2. Drag Flagcast Manager into Applications.
  3. Open it from Applications.

Signed and checked by Apple, so it opens with no warning.

Windows

  1. Open Flagcast-Manager-Setup.exe.
  2. If Windows says it protected your PC, click More info → Run anyway.
  3. Follow the installer, then open it from the Start menu.

Updates

Nothing to download again. When there's a new version, Flagcast Manager tells you and installs it in one click.

You can also check any time with Help → Check for Updates.

Phones and tablets

Flagcast for players

Players scan the QR code on their cart card with the phone camera. The scorecard, leaderboard and par 3 cameras open right away, with nothing to install.

Manager on iPad or phone

Open flagcast.app/golf and choose Share → Add to Home Screen (on Android, the ⋮ menu → Add to Home screen).
